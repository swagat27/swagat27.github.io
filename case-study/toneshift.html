ANDROID APP · FLUTTER + KOTLIN

One rewriter, inside every app

A Flutter app that rewrites text inline in any Android app with the user's own Gemini key, without giving up Gboard.

TL;DR: Every app ships its own mediocre AI rewrite button. ToneShift puts one consistent rewriter, with your own key and your own style, inside every app at once.

Context

Rewriting a message means leaving the app, opening an AI tool, pasting, copying back. ToneShift removes the trip: select text in any app and choose Shorten, Formal, Grammar Fix, Bullet or Polite No.

What was built

Two hooks: an ACTION_PROCESS_TEXT selection popup, and an AccessibilityService floating pill with Undo for everywhere else. The user's Gemini key lives in EncryptedSharedPreferences, never on a server. GitHub Actions builds and publishes a release APK on every push to main; build 5 is live.

What it shows

Native Android depth (accessibility services, text processing intents, encrypted storage) plus a fully automated release pipeline, built solo for personal use.
