ToneShift

Android app

ToneShift rewrites text inline in any Android app, using the user's own Gemini API key, without giving up Gboard. Select text and choose Shorten, Formal, Grammar Fix, Bullet or Polite No, or use the floating pill with Undo.

2hooks: selection popup and floating pill

Why it exists

Every app now has its own AI rewrite button, all different, most mediocre. ToneShift puts one consistent rewriter, with the user's own key and style, inside every app at once.

How it is built

Flutter plus Kotlin. An ACTION_PROCESS_TEXT hook for the selection popup and an AccessibilityService floating pill. Gemini 2.5 Flash does the rewriting; the key is stored in EncryptedSharedPreferences. Every push to main builds and publishes a release APK through GitHub Actions.
