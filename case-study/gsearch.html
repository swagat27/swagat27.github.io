GSearch

interactive web app

GSearch is a CAD aggregator for mechanical components: one search across scattered component libraries, rebuilt in Next.js 15 and live on GitHub Pages. It came out of Swagat's own frustration hunting parts for the Team Agnishul race car.

Next.js 15rebuilt stack
Liveon GitHub Pages
1search for scattered CAD libraries

The problem

Mechanical components live in dozens of vendor libraries, each with its own search. Finding one part means opening many sites and repeating the same query.

What was built

A single aggregator interface over those libraries, designed by someone who actually searches for parts under deadline, then rebuilt properly in Next.js 15.
