BoxPilot

live AI product

BoxPilot is an agentic planner that connects AI agents to a real inbox and calendar, reads the day, and turns it into a plan. It is Swagat's flagship AI product, built solo in February 2026 and running live on GitHub Pages.

18 / 18tests passing
Liveon GitHub Pages
3AI systems: Claude, Gemini, MCP

The problem

Email and calendars hold the plan already, but nobody has time to assemble it every morning. The information exists; the synthesis does not.

What was built

Agents built on the Claude API and MCP, with Gemini in the loop, read Gmail and Calendar, extract commitments, and assemble a prioritised day plan. The rebuild in November 2026 professionalised the repo, tests and demo.

What it shows

End-to-end ownership: problem framing, agent architecture, API integration, testing and a public live demo.
