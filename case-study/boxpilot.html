An inbox that plans itself

An agentic planner that connects AI agents to a real Gmail and Calendar, reads the day, and turns it into a plan.

TL;DR: Email and calendars already hold the plan. Nobody has time to assemble it every morning. BoxPilot's agents do the assembly: commitments in, a prioritised day out.

Context

Every morning starts with the same archaeology: dig through an inbox and a calendar, hold ten commitments in your head, and guess what matters most. The information exists. The synthesis does not.

What was built

Agents built on the Claude API and MCP, with Gemini in the loop, read Gmail and Calendar, extract commitments and deadlines, and assemble a prioritised plan for the day. In November 2026 the project was rebuilt professionally: a clean public repo, a test suite at 18 of 18 passing, and a live demo on GitHub Pages.

What it shows

End-to-end ownership of an AI product: problem framing, agent architecture, API integration, testing, and shipping a public demo that anyone can open.
